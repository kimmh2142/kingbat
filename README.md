# 직장인 킹받게 하기 : 승진의 기술

서강대학교 가상융합전문대학원 캡스톤 게임 프로젝트.
사무실을 돌아다니며 상대를 관찰하고, 몰래 장난친 뒤, 들키지 않고 내 자리로 돌아와야 점수가 확정되는 코믹 눈치 게임.

## 배포

`master` 브랜치에 push하면 GitHub Actions([.github/workflows/deploy.yml](.github/workflows/deploy.yml))가
`npm run build`로 빌드해서 GitHub Pages에 자동으로 올립니다. 보통 1~2분 걸립니다.

- 배포 주소: https://kimmh2142.github.io/kingbat/
- 진행 상황: https://github.com/kimmh2142/kingbat/actions (빌드가 실패하면 여기 빨간 X가 뜹니다)
- 배포된 화면이 안 바뀌면 브라우저에서 새로고침(Ctrl+F5)을 해 보세요.

## 실행 방법

[Node.js](https://nodejs.org/) 20 이상이 필요합니다.

```bash
npm install      # 처음 한 번
npm run dev      # 개발 서버 실행
```

터미널에 나오는 `Local: http://localhost:5173/` 주소를 브라우저에서 엽니다.
코드를 저장하면 화면이 자동으로 새로고침됩니다.

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 (PC + 같은 Wi-Fi 휴대폰) |
| `npm run build` | 타입 검사 후 `dist/`에 배포용 빌드 |
| `npm run preview` | 빌드 결과를 로컬에서 확인 |

| `npm run check:dongi` | 동기 상태 전환 기록, 콕 찌르기, 돌아볼 때 들킴 확인 (약 1분) |
| `npm run check:mobile` | 휴대폰 가로 화면 흉내: 조이스틱 이동, [콕] 버튼, 두 손가락 동시 터치, 세로 안내 확인 |
| `npm run check:hide` | 찌르기 → 화분 뒤 숨기 → 확정, 내 자리 일하는 척, 범위 밖 E 확인 |
| `npm run check:caught` | 3번 들키기 → 하트 3→0, 컷인 캡처·Space로 넘기기, 실패 화면 → 다시 도전 (약 1~2분) |
| `npm run check:clock` | 퇴근 시계 흐름, 컷인 중 멈춤, 마지막 30초 연출, 시간 초과 → 야근 확정 → 다시 도전 |
| `npm run check:items` | 아이템 생기기·줍기·1/2/3·X 넘기기, 포스트잇 붙이기와 탕비실에서 떼기, 껌(자리 비웠을 때 → 돌아와 반응·바로 확정), 붙이다 들킴, 모바일 칸 터치 (약 3~4분) |

| `npm run check:title` | 타이틀 화면(`?title=1`): ↑↓ 고르기, [게임 방법] 4쪽 넘기기·Esc 닫기, 모바일 터치로 열고 닫기, [게임 시작] → 도입 컷신 |

## 휴대폰으로 접속하기

1. PC와 휴대폰을 **같은 Wi-Fi**에 연결합니다.
2. PC에서 `npm run dev`를 실행하면 터미널에 주소가 두 개 나옵니다.
   ```
   ➜  Local:   http://localhost:5173/
   ➜  Network: http://192.168.0.12:5173/   ← 이 주소
   ```
3. 휴대폰 브라우저에 **Network 주소**를 입력합니다. 휴대폰은 **가로 모드**로 돌려서 플레이합니다.
4. 접속이 안 되면:
   - Windows에서 처음 실행할 때 뜨는 방화벽 창에서 **"개인 네트워크" 허용**을 눌러야 합니다.
     놓쳤다면 `Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용`에서 Node.js를 허용합니다.
   - 회사·학교 Wi-Fi는 기기끼리 접속을 막는 경우가 많습니다. 휴대폰 핫스팟에 PC를 연결하면 대부분 해결됩니다.

| 키 | 기능 | 상태 |
|---|---|---|
| WASD / 방향키 | 이동 | ✅ |
| <kbd>`</kbd> (숫자 1 왼쪽 키) | 디버그 표시 켜기·끄기 (충돌 상자, 숨기 범위, 내 자리, 좌표·상태). D는 이동 키와 겹쳐서 이 키로 정함. 주소 뒤에 `?debug=1`을 붙이면 켜진 채로 시작 | ✅ |
| Space 꾹 | 콕 찌르기 (공략 대상 등 뒤 가까이에서). 오래 누를수록 빨라짐 | ✅ |
| Z (또는 F) | 고른 아이템 쓰기. 포스트잇은 동기 등 뒤에서, 껌은 동기가 자리를 비웠을 때 동기 가방 옆에서. 붙이는 0.5초 동안 보이면 들킴. 성공하면 점수가 바로 확정 (포스트잇은 붙이는 순간, 껌은 동기가 돌아와 앉을 때) | ✅ |

터치 기기에서만 화면에 나타납니다. PC에서 확인하려면 주소 뒤에 `?touch=1`을 붙입니다.

| 조작 | 기능 | 상태 |
|---|---|---|
| 화면 왼쪽 절반을 누르고 끌기 | 왼쪽 아래에 조이스틱이 늘 흐리게 떠 있고, 누른 자리로 따라옴. 조금 기울이면 천천히, 끝까지 기울이면 빠르게 이동 | ✅ |

| [아이템] | 고른 아이템 쓰기 ([콕] 버튼은 콕만 함). 아래 가운데 아이템 칸을 눌러서 고름 | ✅ |
| E 버튼 | | 예정 |

## 폴더 구조

```
src/
  scenes/   Boot(임시 그래픽 생성·로딩), Office(사무실 맵)
  systems/  Controls(입력), OfficeMap(맵 그리기·충돌), DebugOverlay
  player/   Player
  npc/      NPC 상태머신·캐릭터별 패턴 (예정)
  data/     맵·소품·수치 데이터 (코드와 분리)
  assets/   텍스처 키와 임시 그래픽 생성기
  ui/       HUD 등 (예정)
public/assets/
  final/    최종 그래픽. 같은 키로 넣으면 임시 그래픽 대신 쓰인다
```

### 그래픽 교체 방법

모든 그림은 텍스처 키(`src/assets/keys.ts`)로 불러옵니다.
`public/assets/final/`에 이미지를 넣고 `src/assets/manifest.ts`에 `키: 'final/파일명.png'`을 한 줄 추가하면
같은 키의 임시 그래픽 대신 그 이미지가 쓰입니다. 크기는 임시 그래픽과 같게 맞추면 위치가 그대로 유지됩니다.
