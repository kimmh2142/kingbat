## STAGE 2 — 과장 박통화 : "퇴근 5분 전에 이것만!"

### 핵심: 계속 움직이는 상대
- 과장은 통화하며 **복사실 ↔ 회의실 앞을 왔다 갔다** 걷는다. 걷는 동안 등 뒤가 빈다 → 따라가면서 콕.
- 앉아 있을 때와 걸을 때 "등 뒤" 방향이 계속 바뀌므로 위치 선정이 STAGE 1보다 어렵다.

### 돌아보는 전조 (말풍선 + 행동)
| 단계 | 모습 |
|---|---|
| 평소 | "네~ 사장님~" 큰 소리로 통화 (통화 중엔 방심) |
| 1단계 (진짜·페이크 같음) | "…네?" 말이 뚝 끊긴다 |
| 페이크 | "아~ 하하하! 그렇죠!" 다시 웃으며 통화 |
| 진짜 | "잠깐만요." 수화기를 손으로 막음 → 돌아봄 |
| 통화 종료 | "네, 그럼 이따 뵙겠습니다!" → **곧바로 돌아봄** |
| 재확인 | 돌아섰다가 **말없이 조용하면** 한 번 더 돌아봄 |

### 방해 요소
- **차장 오의심 (방해 NPC):** 정해진 길로 순찰, 바닥에 시야 부채꼴. "난 다 보고 있어." (대리 순찰 방식 재사용)
- **부장 홍분노 폭발 (이벤트):** 부장실 문 앞에 얼굴이 점점 빨개지는 표시 → 문을 박차고 나와 "전 직원! 다 이쪽 봐!" → 3초간 모든 NPC가 부장 쪽을 본다. 그 전에 숨거나 E 꾹으로 일하는 척해야 한다.
- **[뺄 후보] 모니터 반사:** 과장 모니터 정면 뒤에 서 있으면 들킴.

### 특별 미션 — "전 직원 칼퇴 승인서"
1. 복사실에서 가짜 서류를 줍는다.
2. 과장이 통화하는 사이 결재 서류 더미에서 **방향키 3개 미니게임** (서류 세 장 순서 맞추기)
3. 과장이 그 서류를 들고 부장실로 → 부장: "이게 뭐야아아!" / 과장: "제, 제가 올린 게 아닙니다!"

### 새 아이템 (Lv2)
- **모니터 끄기:** 과장이 자리 비운 사이 사용 → 돌아와서 당황 +25
- **의자 높이 최저:** 자리 비운 사이 사용 → 앉는 순간 "쿵!" +25
- [뺄 후보] 커피컵 스티커

### 클리어 / 실패 대사
- 클리어: 과장 "회의 자료보다 더 신경 쓰이는 일이 생겼어!" → **"과장 공략 성공! 최종 타깃: 대표"** → 엘리베이터 타고 8층으로
- 실패: "이거 인사고과에 반영할 거야!"

## STAGE 3 — 대표 나대표 : "최후의 킹받음"

### 핵심: 감시자 두 명 + 정전
- 8층은 **새 맵**. 엘리베이터 전환 연출로 이동한다.
- 대표실 앞을 비서와 이사가 서로 **다른 방향**으로 지킨다 → 두 시야를 모두 피해야 한다.

### 대표의 행동
| 단계 | 모습 |
|---|---|
| 평소 | 신문 읽기 (골프 퍼팅·창밖 보기는 여유 있으면 추가) |
| 페이크 | 신문을 내리다 말고 다시 올림 |
| 진짜 | 신문을 **완전히 접어 책상에 내려놓음** → 의자를 돌림 |
| 순시 | 1분 정도마다 대표실에서 나와 층을 한 바퀴 (이때 시야 부채꼴 표시) |
| [뺄 후보] 낮잠 페이크 | 꾸벅꾸벅 → 코골이가 멈추면 위험 |

### 방해 요소
- **비서 김비서:** 데스크에서 대표실 앞을 지킴. 정전 중엔 **손전등 빛 = 시야**.
- **이사 엄감시:** 비서와 다른 방향을 봄.
- **[뺄 후보] 인사팀 방문:** 문 열리는 소리 → 3초 뒤 등장, 모두 일하는 척.

### 특별 미션 — "대정전과 최후의 방석"
1. **비서 유인:** 복사기에서 출력 완료 알림을 울려 비서를 복사기로 보낸다.
2. **정전:** 배전반에서 E → 15초간 층이 어두워짐 (손전등 빛만 보임). 직원들 당황 대사.
3. **방석 설치:** 대표가 확인하러 나간 사이 대표 의자에 방귀 방석 → 대표실 밖으로 탈출.
4. 불이 켜지고 대표가 앉는다 → **"뿌우우욱!"** 화면 정지 · 얼굴 확대 · 킹받음 MAX.

### 새 아이템 (Lv3)
- **방귀 방석** (미션 겸용, 설치형)
- [뺄 후보] 명패 바꾸기, 정전 스위치(아이템 대신 미션의 배전반으로 대체)

### 클리어 → 엔딩
- 대표: "…자네였군." → "내가 몇 번을 돌아봐도 자네는 항상 일하고 있더군. 이제 내 자리에 앉아보게."
- **"축하합니다! 당신이 새로운 대표가 되었습니다!"**
- 엔딩: 대표가 된 주인공을 신입이 "콕!" → **"직장생활은 돌고 돈다."**
- 실패: "자네, 오늘이 마지막 출근인가?"

## 그림이 필요한 것 (STAGE 2·3)

자세한 파일 이름·크기는 그림 목록표에 추가할 예정입니다. 우선순위 순:

1. **캐릭터:** 과장(통화 포즈·수화기 막기), 대표(신문 읽기·신문 접기·의자 돌리기), 차장, 비서(손전등), 이사, 부장(얼굴 빨개짐 단계)
2. **8층 바닥·벽·대표실 가구** (대표 책상·의자, 비서 데스크, 배전반)
3. **아이템 아이콘:** 모니터 끄기, 의자 높이, 가짜 서류, 방귀 방석
4. **연출:** 엘리베이터, 정전 화면, "뿌우욱!" 컷, 엔딩 신입
