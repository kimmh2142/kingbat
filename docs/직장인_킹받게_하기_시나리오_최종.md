# 직장인 킹받게 하기 : 승진의 기술

**전체 게임 시나리오 및 플레이 설계안 · 최종본 (3차)**

- **장르:** 2D 캐주얼 아케이드 / 사무실 잠입 / 코미디
- **그래픽 방향:** 《슈의 라면가게》처럼 캐주얼하고 귀여운 2000년대 한국 플래시게임 감성. 캐릭터와 배경은 독자적으로 디자인한다.
- **플랫폼:** PC 웹 우선 (URL 접속), 모바일 가로 모드 확장
- **개발:** Phaser 3 + TypeScript + Vite
- **구성:** 오프닝 → 3개 스테이지(동기 → 과장 → 대표) → 반전 엔딩
- **목표 플레이 시간:** 전체 약 12~15분 (스테이지당 3~5분)
- **핵심 콘셉트:** 사무실을 자유롭게 돌아다니며 상대의 빈틈을 관찰하고, 아이템으로 장난친 뒤 들키지 않고 내 자리까지 도망쳐 오는 눈치 게임

> 점수, 제한시간, NPC 패턴 수치는 초기값이며 플레이 테스트로 조정한다.

## 0. 3차 개정 요약 (2차 대비 변경점)

| 구분 | 2차 기획 | 최종본 |
|---|---|---|
| 스테이지 | 직급 8단계 | **3단계(동기 · 과장 · 대표)**. 단계 수를 줄이고 한 단계마다 요소와 완성도를 높인다 (교수님 피드백) |
| 다른 직급 | 각자 공략 대상 | 대리 · 차장 · 부장 · 이사 · 비서 · 인사팀은 **방해 NPC**로 맵에 등장 |
| 실패 판정 | 경고 3회 | **목숨(Life) 3개**. 실수하면 하트 1개 감소 |
| 시간 | 없음 | **제한시간 + 퇴근 시계 리미트바**. 시간 초과 시 "야근 확정" 실패 |
| 성공 판정 | 장난하면 점수 | **치고 도망까지 성공해야 확정** (Hit & Run) |
| 아이템 | 해금 · 장착 | **맵에서 줍고 쓰는 크레이지아케이드식** 아이템. 단계가 오를수록 강력해짐 |
| 들켰을 때 | 경고 +1 | **들킨 이유를 컷인으로 표시** ("모니터에 비쳤다!", "비서에게 들켰다!") |
| 공간 | 한 맵 | 스테이지마다 **새 구역이 열림** + **조감도 미니맵** |
| 상대 | 제자리 | 상대도 **이동하는 빌런**. 자리 이탈, 순찰, 통화하며 돌아다니기 |
| 엔딩 | 새 대표 + 신입이 콕 | 유지. **"이제 나도 당할 차례"인 유머러스한 열린 결말** |

## PART 1. 게임 시작 시나리오

### SCENE 01. 타이틀

밝은 파스텔 사무실. 직원들이 일하고, 커피를 마시고, 졸고, 과장은 전화 중이다.

- 직원: "아니! 누가 자꾸 건드려?!"
- 주인공: 아무 일 없었다는 듯 키보드를 두드린다.

효과음과 함께 로고가 튀어 오른다. **《직장인 킹받게 하기 : 승진의 기술》**

**메뉴:** 출근하기 / 게임 방법 / 친구 랭킹 / 설정

### SCENE 02. 오프닝 독백 (검은 화면, 한 줄씩 등장)

> 나,
> 조금도 맞고 싶지 않다.
> 나,
> 오로지 **킹받게 하고만** 싶다.
>
> 그저 콕 찌르고 또 찌르고,
> 그러고도 또 찌르고만 싶다.
>
> 모두를 킹받게 할 수만 있다면,
> 한 번도 들키지 않고 그런 것이 허락되는 오늘이
> 내게 와준다면.

※ 원문(때리고 · 패고)은 "실제 폭력 없이 과장된 장난" 원칙에 맞춰 순화했다. 원문 사용 여부는 팀에서 결정한다.

### SCENE 03. 출근 — 오전 8시 59분

엘리베이터 문이 열린다.

- 주인공: "오늘은 제발 아무 일 없이 퇴근하자."
- 동기 이동기: "야! 나 오늘 약속 있거든? 이것 좀 네가 해주라~"
- 주인공: "어? 나도 할 일이…"
- 이동기: "에이~ 우리 동기잖아!" (서류 더미를 털썩 놓고 사라진다)
- 주인공(얼굴 확대): "아…… 진짜 킹받네."

**킹받음 게이지 등장 + 시스템 메시지**

> 킹받컴퍼니의 비공식 승진 도전이 시작되었습니다!
> 눈치껏 장난치고, 들키지 말고, 무사히 자리로 돌아오세요!

### SCENE 04. 사무실 공개

카메라가 출입구에서 대표실까지 훑으며 맵과 모든 직원을 소개한다. 각 직원 머리 위에 직급 라벨이 뜬다. 마지막에 미니맵이 화면 구석으로 접혀 들어간다.

## PART 2. 공통 플레이 시스템

### 2-1. 조작

| 입력 (PC) | 기능 |
|---|---|
| 방향키 / WASD | 상하좌우 자유 이동 |
| Space (꾹 누르기) | 기본 장난 "콕 찌르기" — 누르는 동안 킹받음이 쌓이고, 떼면 멈춤 |
| Space (짧게) | 선택한 아이템 사용 · 설치 |
| 1 / 2 / 3 | 아이템 슬롯 선택 |
| E | 조사 · 상호작용 (모니터 전원, 서랍, 배전반 등) |
| Shift | 일하는 척 / 숨기 (파티션 · 화분 · 서류더미 근처) |
| M | 사무실 조감도 전체 보기 |
| Esc | 일시정지 |

**모바일:** 왼쪽 가상 조이스틱, 오른쪽 [장난] [아이템] [E] [숨기] 버튼. 길게 눌러도 텍스트 선택 · 메뉴가 뜨지 않게 막는다.

### 2-2. 핵심 루프 — "치고 빠지기 (Hit & Run)"

**관찰 → 접근 → 장난 → 도망 → 자리 복귀 → 점수 확정**

1. **관찰:** 상대의 행동과 전조를 보고 빈틈을 찾는다.
2. **접근:** 다른 NPC의 시야를 피해 상대 뒤로 이동한다.
3. **장난:** 콕 찌르기(꾹 누르기) 또는 아이템을 쓴다.
4. **도망:** 장난이 끝나면 점수는 아직 **임시 점수**(게이지에 줄무늬로 표시)다.
5. **복귀:** 내 자리나 안전 지점(숨기 장소)에 도착해 Shift로 일하는 척하면 **점수 확정**.
6. 확정 전에 누군가에게 보이면 임시 점수만 사라지고 **목숨 -1**.

> 1차 프로토타입(v0.7)에서 검증한 "꾹 누르는 동안 쌓이고 오래 누를수록 빨라지며, 상대가 돌아볼 때 누르고 있으면 들킨다" 규칙을 콕 찌르기에 그대로 쓴다.

### 2-3. 관찰 원칙 (1차에서 확정, 유지)

- 이 게임은 시간을 외우는 게임이 아니라 **행동을 읽는 게임**이다.
- 상대 상태: 평소 업무 → 다른 행동 → 의심 → (페이크 또는 진짜) → 실제 확인 → 업무 복귀
- **전조는 캐릭터 행동으로만 보여준다.** 타이핑 멈춤, 고개 갸웃, 컵 내려놓기, 통화 끊김, 의심하는 눈빛, 소리가 끊기는 것 등. "돌아본다!" 같은 큰 경고 문구, 노골적인 카운트다운, 화면 전체가 붉게 깜빡이는 효과는 쓰지 않는다.
- 전조는 두 단계다. 처음엔 진짜와 페이크가 똑같이 보이다가 **다음 동작에서 갈라진다.** 갈라진 뒤 실제로 돌아보기까지 반응할 시간을 준다.
- 페이크는 연속 3번 나오지 않는다. 전조 없이 갑자기 돌아보는 억울한 판정은 만들지 않는다.
- **순찰하는 방해 NPC는 바닥에 시야 범위(부채꼴)를 표시한다.** 공간 정보이고, 공략 대상의 돌아보는 타이밍은 여전히 행동으로만 보여준다.

### 2-4. 점수 · 목숨 · 제한시간

**킹받음 게이지 (0 → 100)**

| 행동 | 킹받음 |
|---|---:|
| 콕 찌르기 (꾹 누르기) | 누르는 시간에 비례, 오래 누를수록 가속 |
| 일반 아이템 장난 | +15 |
| 강력 아이템 장난 | +25 |
| 스테이지 특별 미션 | +30 |
| 서로 다른 장난 연속 성공 (콤보) | +5 |
| 상대 "방심 타임"에 장난 (예: 커피 마시는 중) | ×1.5 |

- 같은 상대에게 같은 장난을 연타해도 점수가 나오지 않는다. 상대가 의심 → 확인 → 업무 복귀를 마쳐야 다시 인정된다.

**목숨 (하트 3개)**
- 장난 중이거나 임시 점수를 들고 있을 때 보이면 하트 -1. 들고 있던 임시 점수는 사라진다.
- 하트 0개면 스테이지 실패. 그 스테이지만 다시 시작하고, 이전 스테이지 기록은 유지된다. 재시작할 때 도입 컷신은 생략한다.

**제한시간 + 퇴근 시계 리미트바**
- 화면 위쪽에 퇴근 시계가 줄어드는 바를 둔다. 스테이지 1은 3분, 2는 4분, 3은 5분.
- 남은 시간이 30초가 되면 배경음이 빨라지고 시계가 째깍거린다.
- 시간 초과 시 **"야근 확정!"** 연출과 함께 실패한다.

### 2-5. 클리어 조건 (재정립)

각 스테이지는 아래 세 가지를 모두 만족해야 클리어된다.

1. **제한시간 안에**
2. **킹받음 게이지 100 확정** (임시 점수 상태로는 안 됨)
3. **스테이지 특별 미션 1개 성공**

목숨이 1개라도 남아 있어야 한다. 결과 화면의 별점은 남은 목숨(★ = 남은 하트 수)과 남은 시간으로 매긴다.

### 2-6. 들킴 원인 컷인 (단간론파 스타일)

들키면 화면이 멈추고, 원인 지점을 가리키는 화살표와 함께 **유리가 깨지듯 원인 문구가 튀어나온다.** 그다음 한 줄 팁이 나와 다음 플레이에 도움을 준다.

| 원인 문구 | 상황 | 한 줄 팁 |
|---|---|---|
| "뒤돌아봤다!" | 공략 대상이 돌아볼 때 장난 중 | 손이 키보드를 떠나면 위험! |
| "모니터에 비쳤다!" | 상대 모니터 반사 각도 안에 서 있음 | 모니터 정면 뒤쪽은 피하자 |
| "비서에게 들켰다!" | 비서 시야 안에서 이동 · 장난 | 비서가 복사기로 가면 기회 |
| "부장 호통에 모두가 돌아봤다!" | 부장 폭발 이벤트 때 숨지 못함 | 분노 게이지가 차면 파티션 뒤로 |
| "통화가 끝났다!" | 과장 통화 종료 직후 장난 중 | "그럼 이따 뵙겠습니다"는 중단 신호 |
| "두 번 확인했다!" | 페이크 확인 뒤 바로 장난 재개 | 돌아선 뒤 조용하면 한 번 더 본다 |
| "발소리를 들켰다!" | 상대 바로 뒤에서 뛰어다님 | 가까이선 천천히 걷자 |
| "도망치다 들켰다!" | 복귀 중 방해 NPC 시야에 걸림 | 복귀 경로를 먼저 확인하자 |

### 2-7. 아이템 (크레이지아케이드식 획득 · 사용)

- 맵 곳곳의 **택배 상자, 서랍, 탕비실 선반**에서 아이템이 나온다. 걸어서 닿으면 줍는다. 일정 시간마다 다른 위치에 다시 생긴다.
- 슬롯은 **최대 3칸**. 1/2/3으로 고르고 Space로 쓴다.
- 스테이지가 오를수록 더 강력한 아이템이 나온다. 이전 스테이지 아이템도 계속 나온다.

| 등급 | 아이템 | 효과 |
|---|---|---|
| **Lv1 장난** | 포스트잇 ("오늘도 월급루팡") | 등에 붙이면 주변 직원이 웃음 → 상대 킹받음 +15 |
| | 껌 | 자리 비운 상대의 가방 손잡이에 붙이기 +15 |
| | 마우스 바꾸기 | 상대가 다른 곳을 볼 때 마우스 위치 바꾸기 +15 |
| **Lv2 장난** | 모니터 전원 끄기 | 자리 비운 사이 E. 돌아와서 당황 +25 |
| | 의자 높이 최저 | 앉는 순간 "쿵!" +25 |
| | 커피컵 스티커 ("월급보다 카페인") | 탕비실 간 사이 컵에 부착 +25 |
| | 가짜 결재 서류 ("전 직원 칼퇴 승인서") | 서류 더미에 끼우기 (미니게임) +25 |
| **Lv3 장난** | 방귀 방석 | 설치형. 앉는 순간 "뿌우욱!" +25, 주변 NPC도 웃음 |
| | 명패 바꾸기 ("칼퇴 추진위원장") | 임원석 전용 +25 |
| | 정전 스위치 | 배전반에서 E. 일정 시간 사무실 어두워짐 |
| **보조** | 아메리카노 | 10초간 이동 속도 증가 |
| | 이어폰 | 다음 "일하는 척"이 한 번 더 버팀 |
| | 서류 더미 | 그 자리에 임시 숨기 장소 생성 (1회) |
| | 모니터 보호필름 | 15초간 "모니터에 비쳤다" 판정 무시 |

### 2-8. 방해 요소 공통 규칙

- 스테이지마다 공략 대상 외에 **방해 NPC 1~2명 + 돌발 이벤트 1~2개**가 등장한다.
- 이벤트는 한 번에 겹치지 않게 하고, 시작 전에 보이거나 들리는 전조를 준다 (발소리, 문 열리는 소리, 전화벨, 분노 표시).

## PART 3. 스테이지 상세

### STAGE 1 — 동기 이동기 : "야, 우리 동기잖아!"

- **역할:** 튜토리얼 + 기본 루프 익히기
- **공간:** 7층 일반 직원석, 탕비실, 화장실 앞 복도
- **제한시간:** 3분 (퇴근 시계 오후 4:57 → 6:00)
- **빌런 포인트:** 일을 떠넘겨 놓고 몰래 쇼핑몰을 보거나, 자리를 비우고 탕비실 간식을 털러 다닌다.

**행동 패턴 (전조)**
- 평소: 타이핑하며 꾸벅꾸벅 졸기, 몰래 휴대폰 보기
- 페이크: "흐음?" 하고 갸웃하지만 **손은 키보드 위** → 다시 타이핑
- 진짜: 손을 무릎에 내리고 **머리카락이 쭈뼛** → 의자를 돌려 뒤돌아봄
- 이동: 30~40초마다 탕비실로 간식을 가지러 간다 (자리 비움 = 설치형 장난 기회)
- 방심 타임: 휴대폰을 떨어뜨려 줍는 동안. 다시 일어나는 타이밍은 랜덤

**장난**
- 기본: 콕 찌르기 (꾹 누르기)
- 아이템: 포스트잇, 껌, 마우스 바꾸기

**특별 미션 — "월급루팡 퍼레이드"**
동기 등에 포스트잇을 붙인 채로 동기가 탕비실까지 걸어가게 만든다. 가는 길에 직원들이 킥킥 웃는다.
- 동기: "뭐야? 왜 다들 웃어?!"

**방해 요소**
- 방해 NPC — 대리 김카페: 커피를 들고 탕비실과 자리를 왕복한다. 시야 부채꼴 있음. 가끔 "커피 좀 사 올래?" 하며 주인공을 붙잡아 3초간 멈추게 한다.
- 돌발 이벤트 — 화장실 찬스: 동기가 화장실에 가며 20초간 자리를 비운다.

**클리어**
- 동기: "아! 진짜 오늘 왜 이러는 거야!!"
- 시스템: **"동기 공략 성공! 다음 타깃: 과장"**
- 주인공: "이 회사… 생각보다 재밌는데?"
- **보상:** Lv2 아이템 등장 시작 / 관리자 구역 개방

**실패 대사:** "야! 너였구나!"

### STAGE 2 — 과장 박통화 : "퇴근 5분 전에 이것만!"

- **역할:** 이동하는 상대 + 다중 방해 + 미니게임
- **공간:** 7층 관리자 구역, 회의실, 복사실 (새로 개방)
- **제한시간:** 4분 (퇴근 시계 오후 5:55, 과장이 업무를 던지는 순간부터)
- **빌런 포인트:** 퇴근 직전에 일을 던지고, 통화하며 사무실을 왔다 갔다 걸어 다닌다.

**행동 패턴 (전조)**
- 평소: "네~ 사장님~" 큰 소리로 통화하며 걷거나 앉기 (통화 중 = 방심 타임 ×1.5)
- 페이크: "…네?" 하고 말이 끊김 → "아~ 하하하! 그렇죠!" 다시 웃음
- 진짜: "잠깐만요." 수화기를 손으로 막음 → 빠르게 뒤돌아봄
- 재확인: 돌아선 뒤 **말없이 가만히 있으면** 0.5초 뒤 한 번 더 확인
- 이동: 통화하며 복사실 · 회의실 앞을 순회한다. 걷는 동안에는 뒤가 빈다.
- 통화 종료 신호: "네, 그럼 이따 뵙겠습니다!" → 곧바로 뒤돌아봄

**장난**
- 기본: 콕 찌르기
- 아이템: 모니터 전원 끄기, 의자 높이 최저, 가짜 결재 서류 + Lv1 아이템

**특별 미션 — "전 직원 칼퇴 승인서"**
복사실에서 가짜 서류를 줍고, 과장이 통화하는 사이 결재 서류 더미에 끼운다.
- 미니게임: 서류 세 장을 정해진 순서로 방향키 배치
- 과장이 그 서류를 들고 부장실로 들어간다 → 부장: "이게 뭐야아아!" → 과장: "제, 제가 올린 게 아닙니다!"

**방해 요소**
- 방해 NPC — 차장 오의심: 정해진 경로로 순찰한다. 시야 부채꼴 있음. "난 다 보고 있어."
- 돌발 이벤트 — **부장 홍분노 폭발:** 부장실에서 분노 게이지(얼굴이 점점 빨개지는 연출)가 차면 문을 박차고 나와 "전 직원! 다 이쪽 봐!" → 3초간 모든 NPC가 부장 쪽을 본다. 파티션 뒤로 숨거나 내 자리에서 Shift로 일하는 척해야 한다.
- 돌발 이벤트 — 모니터 반사: 과장 모니터에 반짝임이 생기면 모니터 정면 뒤쪽에 서 있을 때 들킨다.

**클리어**
- 과장: "회의 자료보다 더 신경 쓰이는 일이 생겼어!"
- 시스템: **"과장 공략 성공! 최종 타깃: 대표"**

**도입**
- 대표: "요즘 회사에 이상한 소문이 돌더군."
- 비서: "누군가 직원들에게 계속 장난을 친다고 합니다."

**행동 패턴 (전조)**

## PART 6. 사무실 맵 · 공간 설계

### 층 구성 (스테이지마다 개방)

| 스테이지 | 개방 구역 |
|---|---|
| 1 | 7층 출입구 · 일반 직원석 · 탕비실 · 화장실 앞 복도 |
| 2 | + 관리자 구역 · 회의실 · 복사실 · 부장실 (문 앞까지) |
| 3 | 8층 임원층 — 대표실 · 비서 데스크 · 이사석 · 배전반 복도 · 휴게 공간 |

### 맵 설계 원칙
1. 모든 책상 사이에 통로가 있고, 막다른 길보다 **돌아가는 길이 2개 이상** 있다.
2. 숨기 장소(파티션, 큰 화분, 서류더미, 탕비실 냉장고 옆)를 구역마다 둔다.
3. **내 자리는 안전 지점**이다. 스테이지가 오를수록 공략 대상과 멀어져서 도망 거리가 길어진다.
4. 지금 공략하지 않는 NPC도 출근 · 업무 · 이동 · 대화를 계속한다. 앞 스테이지 상대들도 맵에 남아 있다.
5. 충돌 영역(책상, 벽)과 상호작용 지점(모니터, 서랍, 의자)을 명확히 구분한다.

### 조감도 미니맵
- 화면 오른쪽 아래에 항상 표시한다. 내 위치(파란 화살표), 공략 대상(빨간 별), 방해 NPC(점), 아이템(반짝이), 잠긴 구역(자물쇠)이 보인다.
- M 키로 전체 지도를 크게 열고 닫는다. 열려 있는 동안 게임은 멈추지 않는다.

## PART 7. 화면 · 디자인

### 아트 방향
- 《슈의 라면가게》처럼 **캐주얼한 아케이드 감성**: 파스텔 핑크 톤, 굵은 외곽선, 2~2.5등신, 과장된 표정, 화면에 큼직한 의성어 (콕! 뿌우욱! 탁!)
- 캐릭터와 배경은 독자적으로 디자인한다. 참고 대상의 캐릭터를 따라 그리지 않는다.
- 캐릭터는 파츠 애니메이션(머리 · 몸통 · 팔)과 표정 교체를 섞어서 만든다. 최종 그래픽 전에는 임시 리소스를 쓰고, 이미지만 바꾸면 교체되는 구조로 만든다.

### 가시성
- 모든 NPC 머리 위에 **직급 라벨** (색으로 구분: 동기 분홍, 과장 주황, 대표 금색 왕관, 방해 NPC 회색 계열)
- 현재 공략 대상은 라벨 옆에 **타깃 아이콘**, 발밑에 점선 원
- 공략 대상의 킹받음 단계는 머리 위 **분노 마크 크기**로 보인다 (게이지 연동)
- 상호작용 가능한 물건에 가까이 가면 살짝 반짝이고 [E] 표시가 뜬다

### HUD (맵 면적 최대화)
- **상단 한 줄:** 스테이지 · 대상 / 킹받음 게이지(확정 + 임시 줄무늬) / 목숨 하트 3개 / 퇴근 시계 리미트바 / 일시정지
- **하단:** 이동 키 안내 / 아이템 3칸 / [장난하기] 버튼
- **오른쪽 아래:** 미니맵
- **미션:** 평소엔 접혀 있다가 Tab이나 아이콘으로 펼친다

### 카메라
- 시작: 사무실 전체 공개 → 플레이어에게 줌인
- 플레이 중: 플레이어 따라가기
- 이벤트 · 들킴: 원인 지점으로 짧게 이동 후 컷인
- 장난 성공: 상대 얼굴 확대 + 효과음
- 스테이지 클리어: 다음 공략 대상에게 포커스

## 핵심 기획 의도

이 게임은 버튼을 빠르게 눌러서 깨는 게임이 아니다. **사무실을 돌아다니며 상대의 행동을 관찰하고, 아이템으로 몰래 장난친 뒤, 들키지 않고 내 자리까지 도망쳐 오는 코믹한 눈치 게임**이다.

직급을 3단계로 줄인 대신, 한 스테이지마다 공간 · 상대의 이동 패턴 · 방해 NPC · 돌발 이벤트 · 아이템이 함께 늘어난다. 들켰을 때 이유를 알려줘서 "다음엔 저렇게 해봐야지"라는 재도전 동기를 만든다. 누구나 한 번쯤 해보고 싶었던 공감 가는 사무실 장난을 과장된 만화 연출로 담는다.

**엔딩 메시지:** "직장생활은 돌고 돈다."
